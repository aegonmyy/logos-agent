# Program-mediated settlements on the public LEZ testnet

On-chain settlement evidence for the three LP-0008 category agents on the
**official public LEZ testnet** (`https://testnet.lez.logos.co`, v0.2.4), run at
`RISC0_DEV_MODE=0`. Generated by `tests/three_testnet_settlements.rs`
(2026-09-08, re-landed after the operator's same-day chain reset killed the
2026-08-22 run's hashes); every transaction below was independently re-verified
against the public RPC after the run.

## Why settlements run through our own program

Each category agent needs its own state-changing on-chain transaction driven
through its own skill dispatch, so the settlement is exercised the way a LEZ
program settles: the agent deploys its own program once, then each agent
settles by invoking it against a fresh public account, and the settlement's
effect (the account's ownership flipping to the program) is read back from
chain state. Program deployment and program calls are public transactions the
sequencer includes.

(Historical note: on 2026-08-22 the public sequencer included token mints but
silently dropped token transfers, which is what originally pushed settlements
onto the program path — see
[`TESTNET_EVIDENCE.md`](TESTNET_EVIDENCE.md). That condition was transient:
the 2026-09-08 post-reset runs land shielded token sends on the public chain,
see [`SHIELDED_TESTNET_PROOF.md`](SHIELDED_TESTNET_PROOF.md). The program path
remains the per-agent settlement evidence because it gives each agent its own
verifiable state change.)

[`testnet-evidence/settlements-v0.2.0/run.log`](testnet-evidence/settlements-v0.2.0/run.log),
the `ProgramDeployment(ProgramDeploymentTransaction ...)` line). Verify:

```bash
curl -s -X POST https://testnet.lez.logos.co -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"getTransaction","params":["810ac460c5bb2b46a3868fb699635be5059496478db48c98809c107a04ee3d67"]}' \
  | jq -r '.result[0]' | base64 -d | wc -c
# -> 343397  (whole transaction body; the bytecode field inside it is 343392)
```

Each settlement is a `program.call` submitted by the agent's skill dispatch
against a fresh public account; the claimer program takes ownership of the
account, and the state change is verified by `getAccount` after inclusion. The
call declares `"spend": 0` (the program's escrow pays the claimed account, so
the call moves none of the agent's own tokens) and passes the agent's spending
threshold as a declared zero-spend; a `program.call` with no declared spend, or
one over the limits, is held for the owner instead of submitting.

## What this evidences

- **F2 (send leg, public testnet):** each agent submits and lands a real,
  state-changing on-chain transaction from its own skill dispatch. (The
  token-transfer `Send` variant is additionally evidenced on this same public
  testnet with real proofs: the agent's shielded spend, blocks 88-118, see
  [`SHIELDED_TESTNET_PROOF.md`](SHIELDED_TESTNET_PROOF.md); the A2A payment
  transfer is evidenced on the local standalone sequencer with real proofs,
  `tests/a2a_two_agents.rs`, and over live Waku in
  `tests/a2a_two_agents_waku.rs`.)
- **F10:** each of the three category agents has its own included on-chain
  settlement transaction (in addition to its own mint, see
  [`THREE_TESTNET_AGENTS.md`](THREE_TESTNET_AGENTS.md)), driven through the
  agent's skill interface, reproducibly.

## Reproduce

```bash
RISC0_DEV_MODE=0 AGENT_TESTNET_URL=https://testnet.lez.logos.co \
  cargo test --test three_testnet_settlements -- --ignored --nocapture --test-threads=1
```

The test deploys the program, settles once per category agent, waits for each
inclusion (bounded, 60 × 3s), and asserts the account ownership flip is
visible on chain (`verified=…` per settlement, and at least two of three must
verify for the test to pass). Public-testnet block production is intermittent;
the run retries through transient outages.

> **Note on ephemerality:** as with all public-testnet evidence, a chain reset
> by the operator invalidates the hashes above; the reproducible test
> regenerates equivalent evidence against whatever testnet is live.
